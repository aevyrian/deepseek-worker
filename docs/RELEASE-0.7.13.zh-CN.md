## 修复内容

1. **仅做 Bootstrap 浏览器健康检查** —— 启动期健康检查与已绑定对话隔离，不再触碰、切换或清空当前对话。
2. **不抢标签页** —— 目标查找与投递核对严格只读：不导航、不插入、不点击、不打开新标签页搜索；
   无法解析目标时以明确原因停止，而不是冒险操作当前草稿。
3. **`wake_target` 作为独立标签** —— 单次投递的 wake 目标优先于全局 `chatBridgeChatUrl`，不再与全局值混用；
   尾部斜杠、无害查询参数、`www.` 主机与 `/g/<project>/c/<id>` 写法解析为同一对话，
   而不同对话 id、首页、登录页与非 HTTPS 地址一律失败关闭（fail closed）。
4. **草稿保护** —— 移除盲目回车兜底。找不到安全的可点击发送控件时，保留并上报已核验草稿，
   不通过未核验的按键事件提交；被 hydration 重渲染丢弃的草稿最多重插三次，
   且只有就绪输入框中存在明确匹配的消息键时才允许一次有界的安全草稿恢复。
5. **Outbox 阶段崩溃恢复** —— 持久化已脱敏的阶段诊断，并在原地扩展 Outbox 记录，
   使阶段中途中断的投递可在重启后核对，而不是盲目重发；旧格式 Outbox 记录仍可读。
6. **去重、ACK 身份与有界重试** —— 发送与核对使用同一对话身份，持久化短租约避免并发核对，
   重试为有界指数退避并保留失败诊断，Cloud 确认独立重试且不重发消息。

## 安装方式

只能通过**官方 Harness Plugin Manager**（`dsh plugin --profile desktop`）安装。
不要手工复制文件到 profile 目录，也不要把 profile 指向未核验的 tarball。

- 本版本的插件来源为 GitHub tag `v0.7.13`（或其指向的确切提交）。
- **安装后必须重启 Harness。** 安装本身只替换磁盘上的包，内存中仍运行旧运行代际；
  不重启不会加载 `0.7.13`。
- 升级前请停止或 drain 正在运行的业务任务，并保留现有 Connector、profile、配置与 Outbox 备份。
  不得清空 Outbox，不得重发待处理的 `[DSW]` 消息。
- 回滚目标：从 tag `v0.7.12` 重装 `0.7.12`。
